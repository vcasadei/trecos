# Custom fields and settings

## Custom fields

Record details the built-in fields don't cover. A field has a name and a type:

| Type | What you enter | Example |
|---|---|---|
| Text | anything | Firmware: Klipper |
| Number | a number, with an optional unit shown after it (no conversion) | RAM: 4 GB |
| Date | a date such as 9/30/2026 (30/09/2026 in Portuguese) | Purchase date |
| Yes/No | tap Yes or No; tap again to clear | Under warranty |

A value that doesn't fit the type, such as "four" in a Number field, is
rejected, and the item isn't saved until you fix it.

### Fields for every item in a house

Settings > **Custom fields** > **Fields for every item** lists the current
house's fields. Add one with a name and type. It then appears, empty, under
**More fields** on every item's form in that house. Filling it in is always
optional.

- **Rename** keeps every value already entered.
- **Delete** first tells you how many items have a value. Nothing changes
  unless you confirm, and confirming removes those values.
- When you create a house and copy categories and tags from another house,
  its fields are copied too (without values).

### A field for one item only

In an item's form, open **More fields** and tap **Add a field to this item**.
Choose a name and type, then fill in the value. The field appears only on that
item. Leaving it empty and saving removes it.

Moving or copying an item keeps its values. When it goes to another house, a
value goes to that house's field with the same name and type. If there is none,
it stays as a field of that item.

Text values are found by Search as part of the description.

## Settings

Settings apply at once and are kept on this phone only; they are not synced.

| Section | Setting | Default |
|---|---|---|
| General | Language: English or Português (Brasil) | the phone's language if supported, else English |
| General | Currency | your region's currency |
| General | Start on: Home or Search | Home |
| Appearance | Theme: Follow system, White, Dark | Follow system |
| Appearance | House colour band: Automatic, Always, Never | Automatic (two or more houses) |
| Appearance | List view: Condensed or Detailed | Condensed |
| Appearance | Detailed-view extras: up to 3 of categories, tags, total value, brand, model, serial number, QR code, date added, last changed and custom fields | Categories |
| Items & photos | New item starts with: Form or Photo | Form |
| Items & photos | Image source: Camera, Gallery, Ask every time | set by the first-use prompt |
| Items & photos | Tags of the current house | |
| Custom fields | Fields for every item of the current house | |
| Trash | The current house's trash | |
| About | Version | |

**Changing the currency** only changes the symbol: R$ 3.500,00 becomes
US$ 3.500,00. Trecos warns you first, and Cancel keeps the old currency.

Security, Sync & backup, Help and Support Trecos arrive in later versions.
