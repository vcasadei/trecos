# Search

The **Search** tab finds anything in all your houses, and with nothing typed it
lists every item.

| Control | What it does |
|---|---|
| Search field | Results update as you type. Each word matches the start of a word, every word must match, and case and accents don't matter: "rasp 4" finds "Raspberry Pi 4", "cabeca" finds "Cabeça" |
| **Items / Containers / Both** | What to list; Items by default |
| **Match in** | Name and description (default), Name only, or Description only. "Name" also covers brand, model, serial number and QR code |
| **Filters** | Houses, categories and tags. Several values in one filter match any of them; several filters must all match. A category group includes its subcategories. Filters stay until you tap **Clear all** |
| **Sort** | Name (A to Z), date added, or unit price; the arrow reverses the order. Items without a price always come last |
| QR button | Scanning arrives in version 0.7 |

Each result shows where it is, starting with its house in the house's colour,
so two boxes with the same name in different houses are easy to tell apart.

**Search in this container**: in a container's menu (⋮), this opens Search
limited to that container and everything inside it. Tap the container's chip
to search everywhere again.

What you type is never stored.
