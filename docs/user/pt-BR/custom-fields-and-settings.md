# Campos personalizados e ajustes

## Campos personalizados

Registre detalhes que os campos padrão não cobrem. Um campo tem nome e tipo:

| Tipo | O que você digita | Exemplo |
|---|---|---|
| Texto | qualquer coisa | Firmware: Klipper |
| Número | um número, com uma unidade opcional mostrada depois (sem conversão) | RAM: 4 GB |
| Data | uma data como 30/09/2026 | Data de compra |
| Sim/Não | toque em Sim ou Não; toque de novo para limpar | Na garantia |

Um valor que não combina com o tipo, como "quatro" num campo Número, é
recusado, e o item só é salvo depois que você corrigir.

### Campos para todos os itens de uma casa

Ajustes > **Campos personalizados** > **Campos para todos os itens** mostra os
campos da casa atual. Adicione um com nome e tipo. Ele passa a aparecer, vazio,
em **Mais campos** no formulário de todos os itens dessa casa. Preencher é
sempre opcional.

- **Renomear** mantém todos os valores já preenchidos.
- **Excluir** primeiro diz quantos itens têm valor. Nada muda sem sua
  confirmação, e confirmar remove esses valores.
- Ao criar uma casa copiando categorias e tags de outra, os campos também
  são copiados (sem valores).

### Um campo só para um item

No formulário do item, abra **Mais campos** e toque em **Adicionar um campo a
este item**. Escolha nome e tipo e preencha o valor. O campo aparece só nesse
item. Se você deixar vazio e salvar, ele é removido.

Mover ou copiar um item mantém os valores. Se ele for para outra casa, o valor
vai para o campo dessa casa com o mesmo nome e tipo. Se não houver, fica como
campo daquele item.

Valores de texto são encontrados pela Busca como parte da descrição.

## Ajustes

Os ajustes valem na hora e ficam só neste celular; não são sincronizados.

| Seção | Ajuste | Padrão |
|---|---|---|
| Geral | Idioma: English ou Português (Brasil) | o idioma do celular, se houver suporte; senão, English |
| Geral | Moeda | a moeda da sua região |
| Geral | Abrir em: Início ou Buscar | Início |
| Aparência | Tema: Seguir o sistema, Branco, Escuro | Seguir o sistema |
| Aparência | Faixa de cor da casa: Automática, Sempre, Nunca | Automática (duas ou mais casas) |
| Aparência | Visualização da lista: Compacta ou Detalhada | Compacta |
| Aparência | Extras da visualização detalhada: até 3 entre categorias, tags, valor total, marca, modelo, número de série, código QR, data de inclusão, última alteração e campos personalizados | Categorias |
| Itens e fotos | Novo item começa com: Formulário ou Foto | Formulário |
| Itens e fotos | Origem da imagem: Câmera, Galeria, Perguntar sempre | definida na primeira vez |
| Itens e fotos | Tags da casa atual | |
| Campos personalizados | Campos para todos os itens da casa atual | |
| Lixeira | A lixeira da casa atual | |
| Sobre | Versão | |

**Mudar a moeda** só troca o símbolo: R$ 3.500,00 vira US$ 3.500,00. O Trecos
avisa antes, e Cancelar mantém a moeda anterior.

Segurança, Sincronização e backup, Ajuda e Apoie o Trecos chegam em versões
futuras.
