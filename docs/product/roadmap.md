# Roadmap

Trecos v1.0 is delivered through incremental releases, each independently
testable. The task-level plan is `openspec/changes/trecos-v1/tasks.md`.

## To 1.0

| Release | Scope | Distribution |
|---|---|---|
| 0.1 | Foundation: project, licence and docs, CI, themes, palette, languages, bottom bar, text safety, headless dev setup | - |
| 0.2 | Places and items: houses, nested containers, items, quantity and price, breadcrumbs, values, colours and icons, first run | Signed APK on GitHub Releases |
| 0.3 | Categories and tags, with suggestions | GitHub Releases |
| 0.4 | Organize: move, copy, duplicate (also between houses), multi-select, trash and the container-delete flow | GitHub Releases |
| 0.5 | Photos | GitHub Releases |
| 0.6 | Search, with list views | GitHub Releases |
| 0.7 | QR codes | GitHub Releases, plus the Play closed test |
| 0.8 | Custom fields and full settings | GitHub Releases, Play closed test |
| 0.9 | App lock and profile | GitHub Releases, Play closed test |
| 0.10 | Local backup (export and import) | GitHub Releases, Play closed test |
| 0.11 | Google Drive sync (behind a build flag) | GitHub Releases, Play closed test |
| 0.12 | Database encryption (behind a build flag) | GitHub Releases, Play closed test |
| 1.0 | Launch: FAQ, contact, rating, tip jar, About, performance pass, Play listing | Google Play production |

## After 1.0

In this order:

1. **1.1** OCR prefill from packaging text (on-device), feeding category suggestions.
2. **1.2** House sharing.
3. **1.3** Attribute fields suggested from the name (brand, RAM…).
4. **1.4** Grid view for tablets and wide screens.
5. **1.5** Photo search (on-device image matching).
6. Multiple users on one phone.
