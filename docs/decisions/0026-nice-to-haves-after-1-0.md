# 0026. Nice-to-haves after 1.0

- **Status:** Accepted
- **Date:** 2026-09-28
- **Change:** `trecos-v1` (docs/product/roadmap.md)

## Context

All are out of v1 except category suggestions (moved into v1, 0019). Order after 1.0: OCR prefill, house sharing, attribute fields, grid view for large screens, photo search, then multiple users on one phone. House sharing is not the same as multiple users.
