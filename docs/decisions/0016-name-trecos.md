# 0016. Name: Trecos

- **Status:** Accepted
- **Date:** 2026-09-28
- **Replaces:** the working name "Cubby"
- **Change:** `trecos-v1` (proposal (Project foundation))

## Context

The working name was **Cubby** ("Cubby - Offline First Home Inventory" in the
original draft). It had to change:

- **A near-identical app already exists**: "Cubby - Home Inventory" on iOS,
  in the same category, would confuse users and invites a trademark dispute.
- **The name is crowded**: many apps, products and businesses already use
  "Cubby", which makes the app hard to find in store search and hard to
  protect as a trademark.
- **The first alternatives were taken too**: "Whereabox" and "Tuckaway"
  already exist, and later candidates (Stowdex, Thingdex, Stashnook, Stowvia,
  Nookstow, Boxdex and others) were rejected.

Candidates were checked against Google Play, the App Store, the web, domain
availability and trademark registries before one was accepted.

## Decision

Rename the product to **Trecos** (Brazilian slang for "stuff"): domain `trecos.app`, package `app.trecos`, Play title "Trecos: Home Inventory", Drive folder `Trecos`, repository `vcasadei/trecos`.

## Consequences

The GitHub repository was renamed in task 1.1. The user checked Brazil's INPI and the US trademark office and found no conflict for "Trecos". Historical documents (the original draft, the planning case study, the proposal and task 1.1) keep the old name, because they record the rename.
