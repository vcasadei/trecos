# 0001. License: PolyForm Noncommercial 1.0.0

- **Status:** Accepted
- **Date:** 2026-09-27
- **Change:** `trecos-v1` (proposal (Project foundation))

## Context

The app must stay free, allow anyone to use and build on it with attribution, and forbid charging for it without a paid licence. F-Droid inclusion is not a goal.

## Decision

License Trecos under **PolyForm Noncommercial 1.0.0**: source-available, public on GitHub. Commercial use needs a separate licence from the maintainer. Contributions come in under a CLA so dual licensing stays possible.

## Consequences

Not OSI open source; no F-Droid. Third-party components keep their own licences. See `LICENSE`, `COMMERCIAL.md`, `CLA.md`.
