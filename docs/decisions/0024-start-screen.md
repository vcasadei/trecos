# 0024. Start screen

- **Status:** Accepted
- **Date:** 2026-09-28
- **Change:** `trecos-v1` (design D13; spec settings)

## Context

Which screen opens first.

## Decision

A setting: start on **Home** (default) or Search. Home opens at the top of the **last-used house**. Search does not open the keyboard automatically.

## Consequences

Stored per device in DataStore.
