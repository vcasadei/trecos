## Quando você precisa de uma licença comercial

| Uso | Licença necessária |
|---|---|
| Usar o app para o inventário da sua casa | Nenhuma |
| Uma instituição de caridade, escola ou órgão público usando o app | Nenhuma |
| Modificar o código para uso pessoal ou não comercial | Nenhuma |
| Vender o app, ou uma versão modificada dele | Comercial |
| Incluir código do Trecos em um produto pago ou com anúncios | Comercial |
| Uma empresa usando uma versão modificada internamente em trabalho com fins lucrativos | Comercial |

Na dúvida, pergunte.

## Como pedir

Abra uma issue no GitHub com o título **"Commercial license request"**, com o
nome da sua empresa e uma frase sobre o uso pretendido; o mantenedor responde e
leva a conversa para fora do GitHub. Não coloque detalhes confidenciais na
issue.

As licenças comerciais são oferecidas por Vitor Casadei, que detém os direitos
sobre o Trecos e sobre as contribuições sob o
[Contributor License Agreement](https://github.com/vcasadei/trecos/blob/master/CLA.md).
Os componentes de terceiros incluídos no Trecos mantêm suas próprias licenças,
que os termos comerciais não alteram.
